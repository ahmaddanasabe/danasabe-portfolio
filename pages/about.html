My journey

From learning code to building useful software.

I chose Computer Science because I love building things that solve real problems.

I started learning web development independently in 2024, beginning with HTML and CSS before progressing into JavaScript, PHP and MySQL. I kept going because I enjoy seeing an idea turn into something people can actually use.

Since then, I've focused on building practical projects rather than learning technology only in theory. I've also had the opportunity to build a website for a real client, giving me experience working beyond purely academic projects.

Computer Science gives me the foundation behind the code, while building real projects and teaching others keeps me learning and improving.

My long-term goal is to become a full-stack developer and software engineer, while growing DA Code Hub into a software company that creates useful digital solutions for businesses, schools and organizations.
